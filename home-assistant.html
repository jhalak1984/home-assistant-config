Use the dashboard.

  1. Download and extract the template. Open dashboards/main-dashboard.yaml in a text editor. Keep a copy of your existing dashboard before making changes.
  2. Prepare a separate dashboard. Create a new user-controlled dashboard for trying this layout. See the official dashboard guide for dashboard options.
  3. Install the frontend dependencies. Check the types listed below and follow each card author's instructions. Supply the theme and supporting resources, or remove the cards/settings you do not need.
  4. Adapt the entities. Replace the export’s sensor, light, switch, camera and other entity IDs with your own. The template does not create entities or connect devices. Replace the example meter IDs, location and bus sensor too.
  5. Supply your images. The background and device illustrations are not bundled. Replace the image paths with your own, or remove them. The included README lists the referenced filenames.
  6. Import and check. In your new editable dashboard, open its raw configuration editor, paste the adapted YAML and save. Check each section and control before relying on it.

Troubleshooting.

Custom element missing

Check the named custom card is installed and its frontend resource is loaded. Follow that card’s installation instructions.

Entity unavailable

Replace the example entity with one that exists in your setup and confirm its integration is working.

Images missing

The original images were not included. Update the background and image paths to files you supply.

Source & sharing.

The downloadable copy removes location details, internal host addresses, utility meter identifiers and instance-specific vehicle upload paths. Device and room labels remain as examples. It contains dashboard configuration rather than a live connection to my home.
