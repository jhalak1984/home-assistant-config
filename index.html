03 / THE LAB

My homelab.

Read homelab & Home Assistant guides →

A documented network design featuring pfSense, MikroTik switching, UniFi wireless and Proxmox virtualisation. VLAN assignments below represent the documented target design; deployment status is not independently verified.

EDGE

Virgin Media → pfSense

Virgin Media Hub in DMZ, forwarding to a dedicated pfSense firewall/router. No native modem mode in the documented setup.

NETWORK

MikroTik + Netgear

CSS326-24G-2S+RM core switch (SwOS) with a GS728TP-100NAS PoE switch downstream. Two UniFi APs connect to PoE trunk ports.

COMPUTE

Two Proxmox nodes

Each Proxmox host connects to a 10G SFP+ port on the core switch. NAS and self-hosted services support the environment.
